🎮 Jokenpô

Projeto de Pedra, Papel e Tesoura desenvolvido em Python, criado em duas versões para acompanhar a evolução da aplicação e dos conhecimentos adquiridos durante o desenvolvimento.

🕹️ Jokenpô V1

 Primeira versão do projeto, desenvolvida com foco na lógica básica do jogo.

- Escolha do jogador
- Escolha aleatória do computador
- Validação da entrada
- Comparação das jogadas
- Vitória, derrota e empate

🚀 Jokenpô V2

 Versão aprimorada com novas funcionalidades e uma estrutura de código mais completa.

- Criação de funções
- Sistema de placar
- Múltiplas rodadas
- Vitória ao atingir 3 pontos
- Validação de dados
- Opção de reiniciar o jogo
- Uso de while, break e continue
